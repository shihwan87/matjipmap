# 인스타 → 맛집 후보

인스타그램 '저장됨' 컬렉션에 모아둔 맛집 포스트를 읽어 후보를 뽑고,
앱의 **[후보]** 화면에서 등록할지 제외할지 결정하는 도구입니다. PC에서 가끔 손으로 돌립니다.

```
인스타 저장 컬렉션
  → 다운로드 (gallery-dl)
  → 사진 글씨 읽기 (RapidOCR)
  → 가게 이름·동네·업종 뽑기 (Claude)
  → 네이버 지역검색으로 진짜 있는 가게인지 확인
  → Supabase candidates 테이블에 올림
앱 [후보] → [등록] 누르면 등록 폼이 채워져서 열림 → 저장
```

추출은 두 단계입니다. **캡션 + 첫 사진**으로 먼저 묻고, 아무것도 안 나오면 **사진을 전부 읽어** 다시 묻습니다.
그래도 없으면 "맛집 없음"으로 기록합니다.

동작 원리와 설계 배경은 `PATTERN.md`에 있습니다.

## 규칙

- 한 번 처리한 포스트는 다시 보지 않습니다 (`insta_posts` 테이블에 기록).
- 이미 등록된 맛집과 같은 상호는 후보에 올라오지 않습니다.
- **[제외]한 후보라도 다른 포스트에서 다시 나오면 새 후보로 올라옵니다.** 제외는 그 건만 닫습니다.
- 같은 상호가 여러 포스트에서 나오면 후보 하나에 출처가 쌓입니다.

## 처음 한 번만 하는 설정

### 1. DB 테이블 만들기

Supabase 대시보드 → SQL Editor → `supabase/migration-005-candidates.sql` 내용 붙여넣고 Run.

### 2. Python 패키지 설치

이 폴더(`tools/insta`)에서:

```bash
pip install -r requirements.txt
```

### 3. 로그인 정보 파일

`.env.example`을 복사해 `.env`로 만들고 채웁니다.

| 항목 | 값 |
|---|---|
| `MATJIP_LOGIN` | 앱 로그인 이름 또는 이메일 (편집자 이상) |
| `MATJIP_PASSWORD` | 앱 비밀번호 |
| `INSTA_COLLECTION_URLS` | 인스타 컬렉션 주소 (아래 참고) |

컬렉션 주소: 인스타 웹(instagram.com) → 프로필 → **저장됨** → 컬렉션 클릭 → 주소창의 URL.
`https://www.instagram.com/아이디/saved/컬렉션이름/1234567890/` 형태입니다.

### 4. 인스타 로그인 쿠키

gallery-dl이 내 계정으로 저장 목록을 보려면 로그인 세션이 필요합니다.
**Chrome에서 바로 읽는 방식은 동작하지 않습니다** (Chrome 127+ 암호화). 파일로 내보냅니다.

1. Chrome 확장 **Get cookies.txt LOCALLY** 설치 (오픈소스, 외부 전송 없음)
2. instagram.com에 로그인한 상태로 확장 아이콘 클릭 → **Export** (Netscape 형식)
3. 받은 파일을 이 폴더에 `cookies.txt` 이름으로 저장

이 파일은 비밀번호나 다름없습니다. git에는 올라가지 않도록 돼 있지만, 다른 곳에 복사하지 마세요.
나중에 "세션이 만료됐다"는 메시지가 나오면 다시 내보내면 됩니다.

### 5. Claude 로그인 (한 번만)

추출은 Claude Code의 명령줄 모드(`claude -p`)를 씁니다. 구독에 포함돼 있어 따로 돈이 들지 않습니다.
단, 데스크톱 앱 로그인과는 별개라 터미널에서 한 번 로그인해야 합니다.

```bash
npm install -g @anthropic-ai/claude-code
```

```bash
claude
```

열리면 `/login` 입력 → 브라우저에서 로그인 → 끝나면 `/exit`.
(설치하지 않으면 데스크톱 앱에 딸려온 실행 파일을 자동으로 찾아 쓰지만, 그것도 로그인은 필요합니다.)

Claude 없이 쓰려면 `--no-llm` 옵션으로 규칙 방식만 씁니다. 정확도는 떨어집니다.

## 평소에 쓰는 법

이 폴더에서:

```bash
.
un.cmd
```

(`run.cmd`는 `python run.py`를 대신 실행해 줍니다. Windows의 Microsoft Store용 `python` 별칭은
AppData\Roaming을 못 봐서 Claude 실행 파일을 찾지 못하는데, 이 래퍼가 그 문제를 피해 갑니다.)

새 포스트만 받아서 처리하고, 끝나면 새로 올라간 후보 이름을 보여줍니다.
그 다음 앱에서 로그인 → 상단 **[후보]** → 하나씩 **[등록]** 또는 **[제외]**.

처음 돌릴 때는 먼저 결과만 보고 싶다면:

```bash
.
un.cmd process --dry-run --limit 10
```

### 옵션

| 명령 | 하는 일 |
|---|---|
| `.
un.cmd download` | 인스타에서 받기만 |
| `.
un.cmd process` | 받아둔 것 처리만 |
| `--retry-failed` | 네이버에서 못 찾았던 포스트 다시 시도 |
| `--retry-no-venue` | "맛집 없음"으로 끝난 포스트 다시 시도 |
| `--no-llm` | Claude 없이 규칙만으로 |
| `--dry-run` | DB에 쓰지 않고 결과만 보기 |
| `--limit 10` | 앞에서 10개만 |
| `--ocr-images 0` | 사진 글씨 읽기 생략 (빠름, 캡션만 봄). 기본은 2단계에서 최대 10장 |

## 문제가 생기면

| 메시지 | 원인과 해결 |
|---|---|
| `설정이 비어 있습니다` | `.env` 또는 루트 `.env.local`에 빈 값. 메시지에 적힌 항목 채우기 |
| `Supabase 로그인 실패` | 이름/비밀번호 틀림. 앱에서 같은 값으로 로그인되는지 확인 |
| `'viewer' 권한이라 후보를 올릴 수 없습니다` | 관리자에게 편집자 권한 요청 |
| `cookies.txt에 sessionid가 없습니다` | 인스타에 로그인 안 된 상태로 내보냄 |
| `인스타 세션이 만료됐거나` | cookies.txt 다시 내보내기 |
| `claude 오류: Not logged in` | 위 5번. 터미널에서 `claude` → `/login` |
| `search-place: 로그인이 필요합니다` | Supabase 토큰 문제. 다시 실행 |
| `search-place: 검색에 실패` | Supabase에 search-place 함수 미배포 (`supabase/functions/README.md`) |
| 후보 화면에 `후보 테이블이 없습니다` | 위 1번 마이그레이션 실행 |
| `[OCR 비활성]` | `pip install rapidocr-onnxruntime` 다시. 캡션만으로는 계속 동작함 |
| `claude 실행 파일을 찾지 못해` | `python run.py` 대신 `.
un.cmd`로 실행. 그래도 안 되면 `.env`의 `CLAUDE_EXE`에 경로 지정 |
